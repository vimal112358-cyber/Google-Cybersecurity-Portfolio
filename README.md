# Google Cybersecurity Professional Portfolio
Welcome! This repository showcases the hands-on technical labs, incident reports, and security automation scripts I completed while earning my Google Cybersecurity Certificate under the Tech Valley / Innovista scholarship.

## 📁 Portfolio Projects & Labs

### 1. Security Documentation & Incident Response
* **[View Incident Response Playbook](./Incident_Response_Analysis.pdf):** A comprehensive post-incident analysis detailing an exploit vector, containment strategies, and long-term remediation steps mapped to the NIST CSF framework.
* **[View Vulnerability Assessment](./Vulnerability_Assessment_Report.pdf):** A structured risk analysis identifying internal system vulnerabilities for a small business layout.

### 2. Security Automation with Python
* **[View Python Notebook](./file_automation.ipynb):** An interactive Jupyter Notebook automating access control lists (ACLs) by parsing corporate IP files to update security allow-lists.

### 3. Log Analysis & Data Querying with SQL
* **[View SQL Queries](./sql_queries.txt):** A library of SQL scripts used to query organizational relational databases to identify anomalous login spikes, outside logins, and employee machine updates.

* **Operating Systems:** Linux (Ubuntu/Debian CLI)
* **Development & Analytics:** Python 3 (Jupyter), SQL
* **Security Frameworks:** NIST CSF
* **Defensive Concepts:** SIEM logging, Network traffic analysis, Access Control Lists (ACLs)
